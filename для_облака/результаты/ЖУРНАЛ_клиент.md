# Журнал: клиентская версия «Тендер под ключ»

Дата: 3 ноября 2026. Папка: `для_облака/клиент/`. Прототип и git не трогал.

## Что сделано
- Новый проект Vite + React + TS, сборка в один файл `dist/index.html` (около 1,8 МБ, без внешних запросов, шрифты Oswald, IBM Plex Sans и Mono встроены).
- Путь: старт, 6 шагов, индикатор 01–06, «Назад»/«Дальше» (на телефоне прилипают к низу с учётом safe-area), состояние в localStorage, «Начать заново».
- Дизайн «одна краска + один акцент»: бумага, синяя краска, розовый акцент, рамка окна, волосяные линии, растровые точки на старте, тёмная тема, reduced-motion.
- Данные: `data/снимок.json` (его положил другой агент, 750 тендеров, у всех `позиции: null`), `data/регионы.json`, `цена/для_демо.json`, `движок/каталог_демо.csv`. Пример-снимок `data/_пример_снимка.json` собран из демо-выхода движка скриптом `scripts/make_example.py` (24 закупки с позициями; у одной позиции убраны намеренно).
- Сверка: правила (вид товара, числовые условия, единицы) и ИИ через `sample.json`. Для тендеров без позиций сверка по названию и ОКПД2.
- Цена: диапазон из таблицы H, три уровня цены с маржой, итог, контакт с согласием, CSV (через `downloads` на claude.ai, иначе blob).
- `scripts/smoke_test.mjs`: телефон 402×874, компьютер 1440×900, ещё прогон на телефоне с подделкой `window.claude` (ИИ и downloads). Все проверки проходят; скриншоты в `скриншоты/`.

## Что поймано при проверке
- Регулярки с `\w` не видят кириллицу: тип товара не определялся. Заменено на `[а-яё]`.
- «Монитор, подключаемый к компьютеру» принимался за системный блок (порядок типов).
- Числа из «DDR4», «10/100/1000BASE-T» читались как 4 и 10: теперь число берётся только из значений вида «16», «3 шт».
- «А4» кириллицей и «A4» латиницей не совпадали.
- Заголовок «ТЕНДЕРЫ» на телефоне обрезался: размер привязан к ширине и высоте окна.
- Скачивание blob с кириллическим именем в Chromium даёт файл «download»: имя CSV сделано латиницей.

## Не получилось или осталось
- Заявка не уходит никуда, только localStorage (место подключения помечено в `Price.tsx`).
- Живой ИИ на claude.ai не проверен (в этой среде нет claude.ai); проверен на подделке. Для работы нужны `capabilities: {sample: {}, downloads: {}}` при публикации.
- В реальном снимке нет позиций: сверка по названию даёт максимум «почти».
- В таблице цены нет ниши компьютеров: взята ближайшая, это написано на экране.
- Не проверено на настоящем iPhone, только эмуляция Chromium 402×874.
