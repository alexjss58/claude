# Журнал блока J «Материалы продаж»

Дата: 3 ноября 2026. Затрачено: около 25–30 минут работы сессии.

## Что сделано (папка `продажи/`)
- `1_скрипт_звонка_и_интервью.md`: скрипт звонка на 2–3 минуты, сценарий 30-минутного CustDev-интервью (6 блоков), шаблон заметок.
- `2_возражения.md`: 15 возражений с ответами, памятка «чего не делать».
- `3_презентация.md` и `3_презентация.html`: 10 слайдов; HTML без внешних библиотек, стрелки влево и вправо, системные шрифты.
- `3_видео_сценарий.md`: демо на 2 минуты, кадр за кадром.
- `4_договор_шаблон.md`: договор с оплатой за заявку и процентом с победы, 3 приложения; вверху пометка «Не юридическая консультация, проверить юристом».
- `4_что_нужно_от_клиента.md`: ЭП, доверенность (МЧД), доступ к площадкам, безопасная схема.
- `5_данные_клиента_152фз.md`: список обязанностей по 152-ФЗ, трансграничная передача и Claude API, ответ клиенту «где хранятся данные».

## Рыночные цифры
Взяты из `данные/Tender_niches_dataset_3nov.xlsx`, лист «Рейтинг 14 ниш» (закупок в год = 44-ФЗ + 223-ФЗ; млрд ₽; участников 223-ФЗ). Подпись «по данным Тендерплана, ноябрь 2026, оценка», точность ±30%. Данные о лидерах (71 из 75 имеют победы = участиям; участий 7–54) посчитаны по файлу поставщиков; выборка отобрана по числу побед, оговорка вынесена на слайд.

## 5 главных выводов
1. Все материалы построены на принципе «мы готовим, клиент подписывает»: ключ ЭП не получаем и не храним. Это снимает главное возражение и юридический риск.
2. Нельзя обещать победу, отсутствие отклонений и отсутствие ошибок ИИ; в договоре ответственность за отклонение исключена, за ошибку ИИ ограничена (исправление или возврат).
3. Claude API — трансграничная передача. Безопасный путь: не отправлять в него персональные данные (обезличивать), хранить базы с ПДн в РФ. Отдельно проверить доступность сервиса из РФ.
4. Прежде чем звать клиентов, нужно решить модель оплаты (за заявку, процент с победы, базу расчёта процента) и подтвердить цифрами из блока I; в договоре эти поля пока пустые.
5. Статистика «лидеры выигрывают почти всё» получена из отобранной выборки; в клиентских материалах она подаётся с оговоркой, а не как обещание результата.
