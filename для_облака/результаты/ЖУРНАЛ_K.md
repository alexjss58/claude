Время: около 25-30 минут (по часам сессии, замер скриптом: первые 6 минут до сборки данных). WebSearch использовано 8 из 15.

## Сделано
- Проверены ГИСП, Минпромторг, ЕЭК, data.gov.ru, reestr.digital.gov.ru.
- Найден и использован открытый REST API евразийского реестра (ЕЭК), без входа. Выгружено 2 507 записей по ОКПД2 26.20/26.30/26.40/26.51 и ТН ВЭД: `реестры/реестр_ЕАЭС_26xx.csv` и `.xlsx`.

## 5 главных выводов
1. У ЕЭК есть настоящий открытый API без регистрации: можно обновлять данные скриптом за 12 секунд.
2. Для нашей ниши евразийский реестр почти пуст: из 97 349 записей отобрано 2 507, российских 47 (действующих 4), по компьютерам (26.20) всего 9. Нацрежим по России проверяется по ГИСП.
3. ГИСП закрыт (403), но по чужому коду видно, что Минпромторг публикует реестр ПП 719 открытым CSV (около 420 МБ, ежедневно): набор `1000000012-ReestrProducts` на minpromtorg.gov.ru/opendata. Из облака недоступен; нужно проверить с обычного компьютера. Это самый ценный следующий шаг.
4. Условия и цены доступа к ГИСП нигде в найденном не указаны: не выдумываем; запасной путь - ручная проверка по номеру записи и выписке.
5. В продукте проверка позиции = ОКПД2 + модель/производитель → номер записи и срок действия; нужна сверка человеком, нечёткое совпадение названий опасно. Не юридическая консультация.
