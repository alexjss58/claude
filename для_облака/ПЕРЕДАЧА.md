## 5. Полезные детали реализации

- **Формат сверки движка для сайтов («G → F»)** описан в `для_облака/ПОТОКИ.md`. Там же формат цены «H → F».
- **Нацрежим по ОКПД2:** `прототип/src/lib/natreg.ts`; клиентский сайт использует копию. Чтение XLSX/CSV в браузере: `прототип/src/lib/catalog.ts`. Сохранение файлов на claude.ai и вне его: `прототип/src/lib/save.ts`.
- **Сборка.** Оба сайта собираются в один файл через `vite-plugin-singlefile`. `npm run build` = `tsc -b && vite build`. Перед сборкой скрипт синхронизирует внешние данные: в прототипе `scripts/sync_external.mjs`, в клиенте аналогичный.
- **`.gitignore`** разрешает коммитить `для_облака/**/*.xlsx`. Исключены `node_modules` и `клиент/data/_кэш/`.
