Дата сборки: 2026-11-03. Не юридическая консультация.

## Коротко
- Скачать удалось только **Евразийский реестр промышленных товаров** (ЕЭК). У него есть открытый REST API без входа и регистрации.
- **Реестр ГИСП (ПП 719) скачать не удалось**: gisp.gov.ru отдаёт 403, minpromtorg.gov.ru не открывается из облака (обрыв соединения). Данные о нём ниже: что известно и откуда.
- Радиоэлектронный реестр (ПП 878) и реестр ПО: открытой выгрузки в найденных источниках не обнаружено.
- Евразийский реестр для нашей ниши почти бесполезен: из 2 507 отобранных записей российских всего 47 (действующих 4), по ОКПД2 26.20 — 9 записей. Нацрежим по российским позициям проверяется по ГИСП, не по ЕЭК.

## Что лежит в папке
| Файл | Что это |
|---|---|
| `реестр_ЕАЭС_26xx.csv` | таблица «производитель → наименование → ОКПД2 → реестровый номер → дата внесения → срок действия → источник» (разделитель `;`, кодировка UTF-8 с BOM) |
| `реестр_ЕАЭС_26xx.xlsx` | то же, лист «Евразийский реестр» + лист «О выгрузке» |
| `обновить.py` | скрипт обновления (нужны `requests`, `openpyxl`) |
| `журнал_обновлений.log` | строка на каждый успешный запуск |

## Откуда данные
Евразийский реестр промышленных товаров, ведёт ЕЭК. Страница реестра: https://goszakupki.eaeunion.org/erpt/ru/registers/products/ (адрес erpt.eecommission.org перенаправляет на неё). Страница «API» того же сайта описывает четыре открытых REST-метода; для реестра товаров это POST на `https://goszakupki.eaeunion.org/spd/find?collection=erpt.v_goodscollection_prod_public` (не более 1000 записей за запрос, фильтр в синтаксисе MongoDB). Спецификация (PDF, 7 страниц): https://goszakupki.eaeunion.org/erpt/assets/files/ (файл «REST API Государственные (муниципальные) закупки_Реестр промышленных товаров.pdf»). Надёжность: официальный сайт ЕЭК, проверено запросом.

Выгрузка от 2026-11-03: всего в реестре 97 349 записей; отобрано 2 507 (ОКПД2 26.20 / 26.30 / 26.40 / 26.51 или ТН ВЭД 8471, 8517, 8518, 8519, 8521, 8525, 9015, 9024–9031). Действуют 1 415, срок документа истёк у 1 092. Страны: Беларусь 2 304, Казахстан 139, Россия 47, Армения 17. Самая свежая дата внесения в выгрузке: 2026-10-13.

Как читать колонки: «дата внесения» = поле `publishdate` (дата включения в реестр); «срок действия до» = `expertactenddate` (окончание срока документа о происхождении); «статус» = `applicationitemstatus` (2 действует, 5 аннулирована, 7 истёк срок). Поле `user` (ФИО сотрудника ЕЭК) в файл не берём.

## Как обновить
```
python3 обновить.py
```
Скрипт скачивает всё заново (около 12 секунд), отбирает, пишет csv и xlsx, добавляет строку в журнал. Если источник не отвечает или формат API изменился, он печатает «ОШИБКА: ...», завершается с кодом 2 и **не трогает старые файлы**. Я проверил это на заведомо неверном адресе.

## Ограничения
- Это не тот реестр, что нужен для ПП 719 (ГИСП). Это отдельный реестр для госзакупок стран ЕАЭС. По сводке поиска (первичный источник не открывали, «предположение»), автоматического переноса записей из ГИСП в евразийский реестр не предусмотрено.
- Отбор по ОКПД2/ТН ВЭД может включить соседние позиции (26.60, 30.30, 26.515): проверьте колонку «причина отбора».
- Записи с истёкшим сроком оставлены сознательно: видно, что товар был в реестре. Для проверки берите статус «Действует».
- Скрипт и API проверены один день; ЕЭК может изменить API без предупреждения.

## ГИСП (ПП 719): что известно и как получать данные
Что установлено и чем подтверждено:
1. gisp.gov.ru (в т. ч. `/pp719v2/pub/prod/`) отдаёт HTTP 403 на обычный запрос из облака. Проверено нами 2026-11-03. Мы защиту не обходили.
2. minpromtorg.gov.ru из облака не открывается (обрыв соединения, проверено на 3 адресах). Причина неизвестна.
3. **Есть сведения об открытых данных Минпромторга по реестру ПП 719**: набор `1000000012-ReestrProducts`, паспорт `https://minpromtorg.gov.ru/opendata/1000000012-ReestrProducts/meta.csv`, файлы вида `data-ГГГГММДД-structure-N.csv`. Поля: ИНН, реестровый номер, наименование, ОКПД2, ТН ВЭД, нормативный документ, даты, срок действия, баллы. Источник — не официальный, а код чужого открытого репозитория: https://raw.githubusercontent.com/DigitalRevision/Cooperation-Web-Agent/HEAD/sync/providers/minpromtorg.py и docs/SYNC.md (там же: «CSV около 420 МБ, обновляется ежедневно»). Надёжность: «предположение», мы сами файл не видели. Коммерческий сервис «Реестр Гарант» пишет то же (открытая база обновляется ежедневно, только действующие записи): https://vnesenie-v-reestr.ru/analitika-gisp/ (страница закрыта проверкой браузера, цитата — из выдачи поиска; число записей 516 715 оттуда же, дата не указана).
4. Условия доступа к открытым данным (регистрация, ЭЦП, цена): **в найденных источниках сведений нет**. Предположение, что открытые данные бесплатны и без входа, основано только на п. 3 (чужой код качает файл без авторизации).
5. Отдельного API ГИСП для сторонних сервисов поиск не нашёл (4 запроса). Про ЭЦП: в найденном материале она нужна для подписания заявки на включение в реестр в личном кабинете, не для чтения (https://vnesenie-v-reestr.ru/news/lichnyy-kabinet-gisp-minpromtorga-registratsiya-i-vozmozhnosti — из выдачи поиска).
6. Стоимость доступа к данным ГИСП, платных API и справочников: **данных не нашли**. Не выдумываем.

Зеркала на GitHub: готовых актуальных выгрузок реестра не нашли. Нашлись только код: `actovix/gisp.gov.ru_parser` (парсер на .NET, последнее обновление 2025-11-19, 0 звёзд, https://github.com/actovix/gisp.gov.ru_parser), `NIKFIRE4/Underfined_squad` и `DigitalRevision/Cooperation-Web-Agent` (интеграции). Код читали только частично; репозитории из облака не открываются.

Альтернативы, если открытые данные недоступны:
- **Ручная проверка по номеру реестровой записи** в публичном поиске https://gisp.gov.ru/pp719v2/pub/prod/ с обычного компьютера (у поставщика обычно есть выписка; в выписке — номер, ОКПД2, ТН ВЭД, баллы, примеры: https://elpitech.ru/upload/iblock/8d6/ttingj1rmlksld26gmjgzj6t9x444nij/Vypiska_iz_reestra_rossiyskoy_produktsii_10624896_ot_11_26_29_04.pdf).
- Платные справочники и сервисы закупок (Контур, Тендерплан): облачная сессия их не видит; цены не проверяли.
- Скачать файл Минпромторга с обычного компьютера (если п. 3 подтвердится) и положить в `реестры/`; логику разбора можно взять из `обновить.py` по аналогии.

## Радиоэлектронная продукция (ПП 878) и ПО
- Реестр радиоэлектронной продукции ведётся по ПП от 10.07.2019 № 878 и оцифрован в ГИСП (https://ppt.ru/art/zakupki/v-zakupkakh-poyavilsya-reestr-radioelektronnoy-produktsii). Открытую выгрузку или API поиск не нашёл. Нет данных.
- Реестр российского ПО ведёт Минцифры по ПП 1236, сайт reestr.digital.gov.ru (https://www.consultant.ru/law/podborki/reestr_1236/). Из облака сайт не открылся; выгрузка в найденных источниках не описана. Для справки, в проекте не нужен.
- data.gov.ru отдаёт проверку браузера (JavaScript), поиск наборов не делали.

## Как сервис будет этим пользоваться
Позиция техзадания → ОКПД2 → смотрим, есть ли ограничение (правила — отдельный блок D) → по модели/производителю ищем реестровую запись: сначала ГИСП (российский реестр, главный), затем евразийский (`реестр_ЕАЭС_26xx.csv`: товары Беларуси, Казахстана, Армении тоже могут считаться «своими» по правилам госзакупок). Результат: «найдена запись №…, действует до …» или «записи нет, проверьте вручную». Совпадение по названию нечёткое, всегда нужна сверка человеком по номеру записи и выписке.
